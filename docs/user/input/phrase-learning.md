---
title: 记词组
order: 5
description: 把应用里选中的一段文字连同它的拼音记成自己的词组, 以后敲这段拼音就能直接选到它.
---

## 做什么用

名字, 术语, 长串编号这类词库里没有的词, 以前要先完整打一遍, 再从候选里选一次才会被记住.
记词组省掉这一步: 选中已经写好的那段文字, 按一下快捷键, 确认拼音, 回车就把它记成自己的词组.

## 怎么用

1. 先在 "偏好设置 -> 快捷键" 里给 "记词组" 录一个组合键 (Windows 在 "设置 -> 快捷键"), 它缺省没有配.
2. 在应用里选中一段文字, 最多 500 字.
3. 按这个组合键: 候选窗口顶部显示这段文字的拼音, 右侧提示 "回车记词组 / Esc 取消".
4. 拼音可以直接用; 要改就按退格删掉再敲, 音节之间可以用 `'` 分开, 例如 `kai'fa'zhe`.
5. 回车记下, 窗口提示 "已记住词组..."; 按 Esc 放弃, 什么都不记.

选中的文字不会被改动, 也不会被重新输入一遍; 全程只是把它和拼音对起来记在本机.

## 记下之后

- 再敲这段拼音, 这个词就出现在候选里, 并且排在同一个输入串下最前.
- 拼音读不出来时 (生僻字, 英文, 符号) 预填是空的, 自己敲即可; 拼音不必与字数相同, 例如可以把 "青简输入法" 记在 `qingjian` 上.
- 记下的词与自动学到的词一样, 可以用 "删除候选" 键 (macOS 为 `⇧ + 数字`, Windows 为 `Shift + 数字`) 整条删掉.
- 私密输入中 (密码框, 无痕窗口) 与关掉学习时都不记.
